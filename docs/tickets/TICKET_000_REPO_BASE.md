# TICKET 000: Repositorio base

## Objetivo

Crear la base técnica, documental y metodológica de GVO — Guía Virtual OKÚA.

## Alcance

- Crear app Vite React TypeScript.
- Configurar rutas placeholder.
- Documentar reglas no negociables.
- Documentar identidad de Lía.
- Documentar estrategia QR/cámara.
- Agregar metodología de tickets.
- Configurar PWA mínima.
- Agregar progreso secuencial con `localStorage`.
- Agregar pruebas unitarias y smoke e2e.

## Fuera de alcance

- Pantalla real de carga inicial.
- Portada real.
- Estaciones reales.
- Diseño final de Lía.
- Scanner interno funcional.

## Criterios de aceptación

- `npm run check` pasa.
- La app compila.
- Las rutas placeholder existen.
- La documentación base existe.
- Hay commit local.
- Se intenta push al remoto configurado.
