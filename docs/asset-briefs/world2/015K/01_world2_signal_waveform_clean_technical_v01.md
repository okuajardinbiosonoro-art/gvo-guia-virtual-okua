## Function

Represent the plant bioelectric signal as a clear technical waveform. This asset replaces the current magical/organic signal as the primary semantic signal visual.

## Prompt

Create a transparent PNG technical bioelectric waveform for an educational botanical interface. The waveform must be clean, legible, horizontally oriented, and readable on mobile. Use a refined cyan and warm gold signal line with subtle glow, small calibrated points, and light measurement ticks. The design must feel scientific and poetic, not magical. No background, no text, no UI frame, no decorative botanical vines.

## Acceptance Criteria

- Signal reads as waveform/measurement within 2 seconds.
- Works at 360x640 without becoming a purple smudge.
- Can animate with horizontal drift, mask reveal, and opacity pulse.
- Does not include plant branches, petals, mandalas, or decorative clouds as the main form.

## Rejection Criteria

- Reads as magical energy, nebula, lightning, smoke, or floral ornament.
- Needs text labels to be understood as signal.
- Fails on transparent background.
