## Regla histórica

Un texto como `PENDING_HUMAN_REVIEW`, `TEMP`, una puntuación visual o un conteo
de pruebas dentro de un documento histórico describe su fecha de corte. No
anula una aprobación publicada posterior ni debe copiarse al onboarding.
