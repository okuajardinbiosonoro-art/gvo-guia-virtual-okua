Hola, vamos a continuar el proyecto GVO — Guía Virtual OKÚA.

Contexto mínimo:

GVO — Guía Virtual OKÚA es una aplicación web local, mobile-first e insonora para guiar el recorrido OKÚA mediante QR físicos dentro de una red MikroTik sin Internet. El visitante abre la experiencia desde el navegador móvil, sin instalar nada.

GVO no es una app decorativa. Su objetivo es guiar visualmente el recorrido y evitar que el visitante interprete erróneamente que las plantas "hacen música" por sí solas. La explicación correcta es: planta viva -> señales bioeléctricas -> captura/acondicionamiento -> interpretación técnica/artística -> resultado sonoro mediado en el espacio. La app no produce sonido.
