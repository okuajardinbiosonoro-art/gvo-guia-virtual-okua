# 07 - Symbol root

## Imágenes a adjuntar

- portal root master aprobado.

## Qué NO adjuntar

- iconos con letras;
- logos.

## Objetivo

Crear símbolo raíz mínimo.

## Prompt listo para copiar

Crear símbolo pixelart mínimo de raíz/brote para portal de Mundo I. Debe ser simple, legible, color tierra suave o ámbar oscuro, fondo transparente. Sin texto, sin letras, sin icono corporativo, sin complejidad botánica excesiva. Debe funcionar dentro de un portal de 192x288 px.

## Criterios de descarte

- Parece letra o logo.
- Tiene demasiados detalles.
- No se lee en pequeño.
