## Objetivo

Generar 3 candidatos de Lía master para transición raíz.

## Prompt listo para copiar

Crear asset pixelart mobile-first de Lía para GVO, avatar único de guía visual. Lía es robótica blanda + flor andina/orquídea, cuerpo no humano, exactamente cinco pétalos, cabeza cristal opalescente, ojos en media luna cerrada, collar ámbar luminoso, bulbo inferior segmentado. Fondo transparente. Estética pixelart limpia, delicada, orgánica, no 3D. Sin boca, nariz, cejas, brazos, manos, piernas, pies, alas, cabello, ropa ni rasgos humanos. No texto. Imagen centrada, escala apta para exportar a 128x128 px.

## Criterios de descarte

- No tiene cinco pétalos.
- Tiene rostro humano o extremidades.
- No conserva collar ámbar o bulbo inferior.
- Parece render 3D.
