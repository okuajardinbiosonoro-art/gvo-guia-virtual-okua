# 06 - Portal root states

## Imágenes a adjuntar

- portal root master aprobado.

## Qué NO adjuntar

- portales rechazados;
- capturas con UI.

## Objetivo

Generar inactive, activating y open.

## Prompt listo para copiar

Crear tres estados de portal vertical pixelart para Mundo I: Raíz: inactive, activating, open. Mismo tamaño y alineación. Fondo transparente. Paleta crema, ámbar, lavanda y tierra suave. El estado inactive debe ser tenue; activating debe tener glow moderado; open debe estar luminoso pero no saturado. Sin texto, sin UI, sin cueva oscura, sin efecto 3D. Entregar como tres paneles o spritesheet horizontal.

## Criterios de descarte

- Estados desalineados.
- Glow demasiado saturado.
- Cambia forma base del portal.
