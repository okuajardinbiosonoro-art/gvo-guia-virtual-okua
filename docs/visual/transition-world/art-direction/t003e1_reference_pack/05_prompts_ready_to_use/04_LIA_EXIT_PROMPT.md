## Qué NO adjuntar

## Objetivo

Crear frame de salida serena.

## Prompt listo para copiar

Crear un frame pixelart de Lía para salida serena de transición. Lía flota levemente, mirando hacia portal central, con collar ámbar suave. Fondo transparente. Exactamente cinco pétalos, cabeza opalescente, ojos media luna, bulbo inferior segmentado. Sin extremidades ni rostro humano. No texto. Imagen centrada y exportable a 128x128 px.

## Criterios de descarte

- Pose teatral o demasiado dinámica.
- Cambia identidad.
- Fondo opaco.
