# Checklist de aceptacion - Assets Transicion Mundo I: Raiz

## Lía

- [ ] Exactamente cinco petalos.
- [ ] Cabeza cristal opalescente.
- [ ] Ojos en media luna.
- [ ] Collar ambar luminoso.
- [ ] Bulbo inferior segmentado.
- [ ] Sin boca.
- [ ] Sin nariz.
- [ ] Sin cejas.
- [ ] Sin brazos/manos.
- [ ] Sin piernas/pies.
- [ ] No parece niña, mujer, hada, animal, mascota ni flor magica.
- [ ] Fondo transparente.
- [ ] Frames alineados por visor/collar.
- [ ] Legible a 96x96 o 128x128 px.

## Portal

- [ ] Vertical y luminoso.
- [ ] Paleta crema/ambar/lavanda/tierra.
- [ ] No parece gema.
- [ ] No parece capullo.
- [ ] No parece cueva.
- [ ] No parece render 3D.
- [ ] Tiene estados base/open o capas separadas.
- [ ] Glow moderado y controlable.
- [ ] Fondo transparente.

## Simbolo raiz

- [ ] Simple y legible.
- [ ] Sin letras.
- [ ] Sin icono generico.
- [ ] Funciona dentro del portal.
- [ ] Puede animarse con opacidad/escala minima.

## Fondo

- [ ] 9:16 mobile-first.
- [ ] Sin texto.
- [ ] Sin UI incrustada.
- [ ] Zona central limpia.
- [ ] Zona inferior limpia.
- [ ] No saturado.
- [ ] No oscuro/cueva.

## Barra

- [ ] Referencia sin texto.
- [ ] Fina y pixelart.
- [ ] No muestra porcentaje.
- [ ] No muestra numeros.
- [ ] Funciona con DOM/CSS.

## Contact sheet

- [ ] 1440x2560.
- [ ] Incluye referencias canonicas.
- [ ] Incluye candidatos completos.
- [ ] Marca aprobados/rechazados visualmente.
- [ ] No reemplaza assets runtime.

## Runtime readiness

- [ ] Nombres exactos.
- [ ] Dimensiones documentadas.
- [ ] Transparencia real.
- [ ] Peso razonable.
- [ ] Sin recursos externos.
- [ ] Sin audio/video.
- [ ] Aprobacion explicita del usuario.

## Descarte inmediato

Descartar si aparece cualquiera de estos puntos:

- texto incrustado;
- letras falsas;
- brazos/manos/piernas/pies;
- Lía no canonica;
- render 3D;
- portal oscuro/cueva;
- fondo saturado;
- asset con marca de agua;
- imagen remota o dependiente de CDN.
