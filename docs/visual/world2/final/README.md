# Station II final visual evidence

This directory is the curated 016V-R2 proof set. It covers compact and standard mobile viewports, tablet/desktop framing, centered closure, layer-six parameter phases, stable navigation, and post-completion revisit.

Run the included Playwright script while the development server is available at its configured local URL:

```powershell
node docs/visual/world2/final/016V_R2_visual_qa.cjs
```

`layout_measurements.json` records the assertions and viewport measurements. PNG files are direct inspection evidence; they are not runtime assets.
