# Prompt pack - ChatGPT Images - Portada / Intro

Pantalla: `PORTADA / INTRO - EL ARCHIVO VIVO DE OKÚA`

Reglas generales para todos los prompts:

- Crear imagen vertical mobile-first 9:16.
- No incluir textos incrustados.
- No incluir logos inventados.
- No incluir letras deformadas.
- No incluir UI final ni botones con texto.
- Mantener consistencia con Lía como guía visual de OKÚA.
- Usar estilo híbrido editorial orgánico con acentos pixelart sutiles.
- Mantener calidez, claridad y baja saturación de partículas.
- La UI final será DOM/CSS.

## Composición maestra sin textos

Genera una composición vertical 9:16 para la portada de una guía visual llamada OKÚA. La escena es un archivo vivo orgánico-tecnológico, cálido y elegante, con cinco portales verticales al centro sobre una base o pedestal orgánico. Lía flota cerca de los portales como guía amable y luminosa. El Portal I se ve disponible y más cálido; los portales II, III, IV y V se ven presentes pero bloqueados y más discretos. Estilo híbrido editorial orgánico con acentos pixelart sutiles. Sin texto, sin letras, sin logo, sin botones con palabras, sin UI final. Dejar espacio superior para logo DOM y espacio inferior para título y botón DOM.

## Lía portada aislada

Genera a Lía como personaje guía visual aislado sobre fondo transparente o fondo plano fácil de recortar. Lía debe ser una entidad amable, luminosa, orgánica y biomimética, consistente con una guía flotante de OKÚA. Debe verse central, reconocible, serena y activa, con pétalos o formas suaves y un pequeño brillo de collar o centro luminoso. No incluir textos, no incluir logos, no incluir fondo complejo, no incluir múltiples versiones de Lía. Mobile-first, limpia, lista para recorte en Photopea.

## Fondo / sala archivo vivo sin UI

Genera un fondo vertical 9:16 de una sala llamada Archivo Vivo de OKÚA. Debe parecer un espacio orgánico-tecnológico, cálido, biomimético, con profundidad suave y una zona central lista para colocar cinco portales. No incluir Lía. No incluir textos. No incluir botones. No incluir UI final. No saturar con partículas. Dejar espacio superior e inferior respirable para DOM/CSS.

## Portal I - Raíz

Genera un portal vertical aislado o sobre fondo simple, estilo orgánico con acentos pixelart. Debe representar Mundo I: Raíz, sentirse habilitado, cálido, vivo, con energía suave y una idea de origen vegetal/subterráneo. No incluir texto ni número. No incluir logo. Debe poder recortarse como capa PNG. Mantener lectura mobile.

## Candado / lock visual
