# Checklist visual - Portada / Intro

Pantalla: `PORTADA / INTRO - EL ARCHIVO VIVO DE OKÚA`

## Identidad y composición

- [ ] Lía se reconoce como guía principal.
- [ ] Lía respeta su identidad documentada.
- [ ] La pantalla se lee como El Archivo Vivo de OKÚA.
- [ ] El estilo es híbrido editorial orgánico + acentos pixelart.
- [ ] La composición es mobile-first 9:16.
- [ ] No hay saturación de partículas.
- [ ] La referencia no se convierte en una landing genérica.

## Portales

- [ ] Hay cinco portales visibles.
- [ ] Portal I está habilitado.
- [ ] Portales II-V están bloqueados.
- [ ] Los portales bloqueados tienen candado o indicador equivalente.
- [ ] Portal I no abre antes de completar diálogos.
- [ ] Portales bloqueados responden sin navegar.

## UI y textos

- [ ] Botón `Comenzar recorrido` visible.
- [ ] Textos finales son DOM/CSS.
- [ ] No hay textos incrustados en imagen runtime.
- [ ] No hay porcentaje ni textos técnicos.
- [ ] Diálogos de Lía son DOM/CSS accesible.
- [ ] Logo OKÚA no es texto distorsionado por IA.

## Diálogo y gating

- [ ] Tocar `Comenzar recorrido` inicia diálogo obligatorio.
- [ ] Tocar Portal I en primera pasada inicia diálogo obligatorio.
- [ ] Lía explica que las plantas no hacen música por sí solas.
- [ ] Lía explica mediación: señal viva, captura técnica e interpretación.
- [ ] Lía explica que la primera pasada es secuencial.
- [ ] Lía indica que al final habrá revisión libre.
- [ ] Lía introduce Mundo I: Raíz.
- [ ] Portal I solo abre después de completar diálogos.

## Restricciones

- [ ] No hay audio.
- [ ] No hay video runtime.
- [ ] No hay CDN.
- [ ] No hay recursos externos.
- [ ] No hay rutas funcionales sin ticket aprobado.
- [ ] No se implementan estaciones.
- [ ] No se implementa transición entre mundos dentro de portada.

## Reduced motion y accesibilidad

- [ ] Reduced motion evita zoom fuerte.
- [ ] Reduced motion evita desplazamientos amplios de Lía.
- [ ] Portal I comunica disponibilidad.
- [ ] Portales bloqueados comunican estado.
- [ ] Diálogo usa foco/aria-live o equivalente.
- [ ] No se depende solo del color para bloqueo.
