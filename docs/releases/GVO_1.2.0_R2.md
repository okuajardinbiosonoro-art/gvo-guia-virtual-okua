# GVO 1.2.0 R2 · Revisión de gerencia y escritor

José David aprobó esta candidata el 25 de noviembre de 2026. R2 distingue la segunda entrega de ese día. La versión de producto conserva el número 1.2.0. El escritor y gerencia pueden dar conformidad o devolver observaciones. El último despliegue documentado en MOMOTTO_PC es 1.1.3. [Acta de campo](GVO_1.1.3.md).

## Revisión con el editor local

En Windows de 64 bits, extraer la carpeta completa y abrir **INICIAR_GVO.cmd**. Elegir escena e idioma y pulsar **Abrir GVO**. La libreta presenta primero los textos observados en la aplicación. Para proponer un cambio, seleccionar el texto o añadir un cuadro, pulsar **Guardar en PC** y devolver **Exportar todo (.ZIP)**. Comenzar en una carpeta nueva conserva las devoluciones de las otras ediciones con su base correspondiente. El ZIP lleva la guía de lectura, la visita ES/EN, los 16 MP3 y el retrato sintético para probar la foto.
