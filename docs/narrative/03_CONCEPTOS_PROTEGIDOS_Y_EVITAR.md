# 03 — Conceptos protegidos y conceptos a evitar

Este documento no fija un estilo literario obligatorio. Fija límites de coherencia para que los textos no contradigan la experiencia, la interfaz ni el funcionamiento de OKÚA.

## Conceptos protegidos

| Concepto | Cómo debe funcionar en el guion |
| --- | --- |
| Mediación | Idea transversal: OKÚA no es una traducción directa ni magia; es un sistema que media señales, decisiones, espacio y experiencia. |
| Planta viva | Origen sensible del recorrido. La planta no es decoración ni personaje humano. |
| Señal bioeléctrica | Base de Mundo II. Existe como fenómeno, pero no es música por sí sola. |
| Captura y preparación | Evita que el visitante crea que el resultado aparece de manera directa o automática. |
| Interpretación / mapeo | El sistema convierte datos y señales en una experiencia organizada. |
| Prueba y ajuste | Base de Mundo III; el proyecto nace de iteración, límites y mejora. |
| Cadena técnica | Base de Mundo IV; debe mantenerse en orden y sin omitir nodos. |
| Experiencia situada | Base de Mundo V; OKÚA ocurre en un espacio real con plantas, sistema y visitante. |
| Revisión libre | Función del final: permite volver a mundos ya completados. |
| Lía como guía única | Preserva continuidad narrativa y evita introducir otros guías. |

## Conceptos o formulaciones a evitar

| Evitar | Motivo |
| --- | --- |
| “La planta canta” o “hace música sola” | Contradice la mediación. |
| Magia literal | Puede usarse sensibilidad poética, pero no explicación mágica del funcionamiento. |
| Lía como niña, mujer, hada, mascota o flor mágica | Rompe la identidad del avatar. |
| Prometer audio en la app | El proyecto es visual e insonoro. |
| Prometer Internet, AR, cámara, escáner o descarga | Contradice reglas de operación local. |
| Saltar estaciones en primera pasada | Rompe el flujo secuencial. |
| Introducir otros personajes guía | Debilita el rol único de Lía. |
| Texto largo en pantalla móvil | Dificulta lectura para público general. |
| Explicar toda la técnica en estaciones conceptuales | Satura antes de Mundo IV. |

## Regla editorial base

El escritor puede elegir voz, cadencia, metáfora, sensibilidad y tono. La única condición es que el texto final cumpla la función de pantalla indicada en la matriz y no contradiga los conceptos protegidos.
