# Checklist de entrega de textos GVO v1

## Matriz

- [ ] Todos los slots tienen `Texto final`.
- [ ] Los textos largos tienen `Alternativa corta` cuando sea necesario.
- [ ] No se modificaron IDs.
- [ ] No se eliminaron filas.
- [ ] No se agregaron filas sin consultar.
- [ ] Las dudas están en `Notas escritor`.

## Claridad de experiencia

- [ ] Cada pantalla se entiende sin audio.
- [ ] Las instrucciones de interacción son comprensibles para público general.
- [ ] Los mensajes de bloqueo no regañan al visitante.
- [ ] Los textos de carga no parecen errores técnicos.
- [ ] Los botones son breves y claros.
- [ ] Las acciones críticas, como reiniciar, son directas y no poéticas.

## Coherencia GVO

- [ ] No se dice que la planta canta literalmente.
- [ ] No se dice que la planta hace música por sí sola.
- [ ] Lía no queda escrita como humana, niña, hada o mascota.
- [ ] La Estación I no adelanta toda la cadena técnica.
- [ ] La Estación IV sí respeta la cadena técnica completa.
- [ ] La pantalla final no introduce una nueva estación ni teoría nueva.

## Público general

- [ ] Los textos pueden ser entendidos por niños, adolescentes, adultos y adultos mayores.
- [ ] No hay tecnicismos innecesarios sin contexto.
- [ ] La experiencia no depende de conocimiento previo.
- [ ] La lectura en móvil se mantiene clara.
