# Leer primero — Encargo de escritura GVO

Este paquete existe para convertir el recorrido visual de GVO en textos claros, sensibles y funcionales para pantalla móvil. El objetivo no es escribir una explicación técnica del sistema, sino acompañar al visitante para que entienda qué ve, qué acaba de hacer, qué debe hacer después y qué idea debe protegerse en cada momento.

## Qué debe producir el escritor

- Diálogos de Lía.
- Textos ambientales.
- Instrucciones de interacción.
- Mensajes de bloqueo suave.
- Textos de carga y espera.
- Textos de cierre.
- Textos de botones cuando aplique.
- Alternativas cortas para textos que puedan quedar largos en pantalla móvil.
- Notas de duda o justificación cuando una decisión verbal requiera revisión.

## Qué no debe producir

- Diseño visual nuevo.
- Estructura técnica.
- Cambios de navegación.
- Nombres de rutas.
- Lógica de desbloqueo.
- Programación.
- Nuevos personajes guía.
- Explicación técnica fuera de la función de cada pantalla.
- Promesas de audio, Internet, sensores externos o funciones no definidas.
- Cambios en identidad visual o narrativa de Lía.

## Libertad autoral

Este paquete no impone estilo literario. La matriz define función, contexto, longitud sugerida y restricciones de cada texto, pero no obliga una voz cerrada.

El escritor decide tono final, cadencia, metáfora, ritmo y solución verbal. La única restricción es no romper los conceptos protegidos, no confundir la interfaz y no prometer comportamientos que la experiencia no tiene.

## Cómo leer cada fila

Cada fila de la matriz responde una pregunta práctica: qué texto necesita esta pantalla en este estado concreto. Antes de escribir, revisar:

1. `Pantalla / estación`.
2. `Estado`.
3. `Contexto visual`.
4. `Acción previa del visitante`.
5. `Función del texto`.
6. `Concepto obligatorio`.
7. `Evitar`.

Después escribir en `Texto final`, proponer `Alternativa corta` si hace falta, y usar `Notas escritor` para dudas o decisiones autorales.
