# Estación III — Mundo III: Cuaderno Pixel de Pruebas

![Referencia visual](../visual_refs/05_estacion_iii_cuaderno_pixel.png)

**Especificación fuente:** `../source_txt/05_estacion_iii_cuaderno_pixel_especificacion_v1.txt`

## Intención

Mostrar a OKÚA como una bitácora interactiva donde Lía guía la revisión de planta, prototipo y señal para evidenciar que el sistema nació de pruebas, errores y ajustes.

## Función dentro del recorrido

Mostrar proceso: observar, probar, detectar límites, ajustar y mejorar.

## Interacción esperada

Activar tres bloques en orden: PLANTA → PROTOTIPO → SEÑAL; luego aparece sello AJUSTADO y se habilita continuar.

## Modo de uso

Interactivo secuencial en primera pasada; revisión libre posterior.

## Emisor textual principal

Lía / cuaderno. Interfaz para sello, bloqueo y continuar.

## Secuencia funcional sugerida

1. Entrada del cuaderno.
2. Bloque PLANTA.
3. Bloque PROTOTIPO.
4. Bloque SEÑAL.
5. Sello AJUSTADO.
6. Continuar a Estación IV.

## Estados de pantalla para escritura

| Estado | Qué se ve / momento | Función del texto |
| --- | --- | --- |
| w3_intro | Cuaderno cerrado/abierto y Lía | Presentar bitácora |
| w3_planta | Bloque Planta | Observación |
| w3_prototipo | Bloque Prototipo | Prueba material |
| w3_senal | Bloque Señal | Revisión del fenómeno |
| w3_ajustado | Sello Ajustado | Cerrar aprendizaje |

## Textos que debe producir o revisar el escritor

- Entrada de Lía.
- Texto por bloque.
- Texto del sello Ajustado.
- Mensaje de bloqueo suave.
- Cierre.
- Botón continuar.

## Conceptos que deben quedar protegidos

- proceso.
- pruebas.
- errores.
- ajustes.
- bitácora.
- evolución del sistema.

## Conceptos o decisiones que deben evitarse

- sistema perfecto desde el inicio.
- cadena técnica de 8 nodos.
- minijuego complejo.
- collage saturado.
- exceso técnico.

## Nota para escritura

La pauta anterior no define el estilo final. Define qué necesita resolver cada texto dentro de la pantalla. El escritor puede modificar ritmo, voz, metáfora y construcción verbal, siempre que no se pierda la función de pantalla ni se contradigan los conceptos protegidos.
