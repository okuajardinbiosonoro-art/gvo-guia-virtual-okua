# README 006I - Mapa visual de cierre pre-PDFs

006I actualiza la capa editorial del Atlas Visual despues de la Tanda 4, incorporando los mockups aprobados 006H para cerrar los pendientes de Mundo III y Mundo V.

## Estado del Atlas

- La carpeta Atlas contiene 47 PNG directamente en la raiz.
- No se crean subcarpetas, no se renombran PNG y no se editan imagenes.
- `manifest_006i_atlas_assets_consolidated.csv` consolida capturas actuales, mockups aprobados y referencias base.

## Mapa imagen-slot

- `manifest_006i_slot_image_map.csv` cubre 197/197 slots de la matriz base.
- Cada slot tiene un `asset_primary` existente dentro de la carpeta Atlas.
- Estacion III queda cubierta con referencia base para intro/planta y mockups 006H para prototipo, senal, ajustado, bloqueo y cierre.
- Estacion V mantiene el mockup de area activa 006F para mapa general y usa mockups 006H para bloqueo y cierre.

## Pendientes visuales

`manifest_006i_pending_visuals.csv` queda sin filas de pendientes bloqueantes. Los grupos cerrados por Tanda 4 son `w3_prototipo_review`, `w3_senal_review`, `w3_ajustado_active`, `w3_soft_block`, `w3_complete_closure`, `w5_soft_block` y `w5_complete_closure`.

## Uso editorial

Las imagenes son representativas por patron visual o estado. No existe una imagen por cada dialogo ni debe interpretarse el mapa como una lista de capturas unitarias.

Los textos visibles en los mockups son placeholders cuando aplique; la fuente de verdad textual sigue siendo la matriz narrativa base y sus derivados editoriales.

Con este cierre, el Atlas queda listo para maquetacion de PDFs y Excel editorial.
