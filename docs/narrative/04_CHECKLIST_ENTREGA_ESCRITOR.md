# 04 — Checklist de entrega para escritor

## Entregables esperados

- Matriz de textos completa en `.xlsx`, `.csv` o formato acordado.
- Texto final por cada ID marcado como `Pendiente escritor`.
- Alternativa corta para textos que puedan no caber en móvil.
- Notas del escritor cuando una fila requiera ajuste de intención, extensión o ubicación.
- Dudas agrupadas por pantalla, no dispersas en mensajes sueltos.

## Criterios de revisión funcional

| Criterio | Debe cumplirse |
| --- | --- |
| Correspondencia con ID | Cada texto debe conservar su ID para poder implementarse. |
| Claridad de estado | El texto debe corresponder al momento exacto de pantalla. |
| Público general | Debe poder entenderse sin conocimiento técnico previo. |
| Lectura móvil | Debe ser viable en pantalla vertical móvil. |
| Sin contradicción conceptual | No debe negar mediación, flujo secuencial ni reglas de Lía. |
| Libertad autoral preservada | El texto puede tener voz propia siempre que cumpla la función. |
| Alternativa corta | Cuando el texto sea largo, debe existir versión reducida. |

## Reglas de aprobación interna

1. El escritor entrega la matriz completa.
2. El equipo GVO revisa primero coherencia conceptual, no estilo.
3. Se marcan textos como `Aprobado`, `Ajustar` o `Duda`.
4. Solo después de aprobar se trasladan textos al código o al archivo de copy runtime.
5. Ningún texto final debe quedar implementado sin ID rastreable.
