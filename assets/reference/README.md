# Referencias visuales

Esta carpeta guarda referencias visuales autorizadas del proyecto.

Reglas:

- No usar referencias como fondo o asset runtime sin ticket explícito.
- No mezclar imágenes exploratorias con assets aprobados.
- Registrar origen, fecha y estado de aprobación cuando se agregue una referencia.
- Las pantallas de referencia viven en `assets/reference/screens`.
